### Design game levels
See Instructions: Timed typer.

- Design at least five unique game levels that increase in difficulty.
- Add at least three new function definitions to typer.py that support your leveling system.
- Use the functions to build your game logic in main.py.
- End the game with some indication of the player’s progress.
We’ve started with a single-level speed typing game with three rounds.
Your levels can vary the combination of word length, number of words, time limit, and number of rounds - or you can build original game mechanics of your own!
